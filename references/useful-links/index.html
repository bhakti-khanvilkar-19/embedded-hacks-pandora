References

Useful links

General-purpose references worth keeping close. Anything specific to one topic belongs on that topic's own page instead — this list is for material that spans domains or is just generally handy.

Specs and standards

  • Linux kernel documentation — Documentation/ in the kernel source tree, especially the device tree bindings under Documentation/devicetree/bindings/.
  • Device Tree Specification — the formal reference for device tree syntax and semantics, useful whenever Linux drivers and device tree overlays don't line up.

Tools

  • i2c-tools — i2cdetect, i2cget, i2cset for I2C bring-up.
  • libgpiod — modern userspace GPIO access, replacing sysfs GPIO.
  • minicom / picocom — serial terminal clients for UART console access.
  • tcpdump / Wireshark — packet capture, invaluable when debugging anything under Networking.
