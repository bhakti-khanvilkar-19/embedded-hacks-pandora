Motherboard

Every component covered so far — CPU, RAM, storage, GPU — needs somewhere to physically plug in and a way to actually talk to each other. The motherboard is that somewhere: the board every other piece of hardware connects to, both electrically and physically.

Quick reference
What it is
The main circuit board a computer's components all plug into, providing both power delivery and data pathways between them.
Mental model
A city's road and utility network — every building (component) needs a physical connection to it before it can receive power or talk to anything else.
Key numbers
Form factors (ATX, Micro-ATX, Mini-ITX) trade expansion room for physical footprint.
Reach for it when
Describing what physically holds a system together and routes power/data between every other component.

The chipset

The chipset is the set of controller chips managing communication between the CPU and everything else — storage interfaces, USB ports, and more. It's a major factor in what a given motherboard actually supports: how many drives, how many high-speed expansion slots, which CPU generations it can drive at all.

Buses — the actual pathways

PCIe
The high-speed lanes a GPU and other add-in cards connect through — more lanes and a newer generation both mean more bandwidth available.
SATA / NVMe
Storage interfaces — SATA is the older, slower standard; NVMe runs storage directly over PCIe lanes for dramatically higher throughput, matching the speeds described on the ROM & Storage page.
USB
The external-peripheral bus — keyboards, mice, external drives, all sharing the motherboard's USB controller bandwidth.

Form factors

Standardized physical sizes — ATX (full-size, most expansion room), Micro-ATX (smaller, fewer slots), Mini-ITX (smallest common standard, minimal expansion) — trade physical footprint directly against how many components a board can host at once. The tradeoff is entirely physical: a smaller board isn't slower, it simply has less room.

Expansion slots

  • PCIe slots — for a GPU or other add-in cards.
  • RAM slots (DIMM) — how many memory sticks, and often at what maximum speed, a board supports.
  • M.2 slots — compact, direct-to-PCIe slots for NVMe storage, no cables required.

Real-world applications

  • Every desktop, workstation, and server — the direct case this page describes.
  • Laptops — a custom-shaped, non-standard board doing the exact same conceptual job, just not built to any interchangeable form factor.
  • Embedded single-board computers — a Raspberry Pi–style board is a tiny, fixed-component version of the same idea — CPU, RAM, and I/O all on one board, just without swappable parts — see the Embedded domain.

Gotchas

Field notes
  • Compatibility mismatches — wrong CPU socket, unsupported RAM type/speed, a form factor that doesn't physically fit the case — are the single most common category of build mistake, almost always avoidable by checking the motherboard's own specification sheet first.
  • A chipset can quietly cap what's possible even with otherwise-compatible parts — limited PCIe lane counts or storage interfaces are a real, easy-to-miss constraint.
  • A motherboard's own firmware (BIOS/UEFI) is itself stored in non-volatile memory on the board — see ROM & Storage's boot role section for why that has to be true before anything else on the system can even start.
